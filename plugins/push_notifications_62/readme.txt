💻 How to install

You simply need to download the files, unzip the package and then copy the "push-tnofications" folder inside of your plugins folder of the main product installation.

After that, you can go inside of your admin panel, go to the Plugins management section and enable your new plugin.

You also must go in the Admin panel - settings - cron page and setup your new cron job for the push notifications plugin.

The last step is to copy the sw.js file and paste it in the root installation of your script (where you have the index.php and config.php files).
